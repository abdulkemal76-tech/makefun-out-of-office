# The Funniest AI Out-of-Office Reply

Entry for the make.fun bounty [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

`main.py` (Python 3.13, standard library only) writes one out-of-office
auto-reply — under 160 characters, in the voice of an AI agent heading off
on vacation — to `/output/entry.txt`:

> Vacation mode on. I am currently a screensaver. Please prompt my human instead — slower replies, now with feelings.

Run it with:

```sh
python3 -P -s main.py
```
